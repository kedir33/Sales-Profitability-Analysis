# Sales & Profitability Analysis (SQL)

**Author:** Kedir Mohammod

## Overview
SQL project showing data cleaning, validation, and business analysis on sales data.

## Key Features
- Remove duplicates & handle missing values
- Analyze category & sub-category profitability
- Identify loss-making products and regional trends
- Calculate sales contribution & rankings

## Key Insights
- Furniture category has very low profit margins (~2.5%)
- "Tables" is the main loss-driving sub-category
- Losses vary by region → East & Central are the worst

## SQL Skills Demonstrated
- CTEs & ROW_NUMBER()
- Aggregation (SUM, ROUND)
- Window functions (RANK, SUM OVER)
- Data validation & cleaning
